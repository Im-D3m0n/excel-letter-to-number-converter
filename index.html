Column letter ↔ number

In Excel and Google Sheets, columns are labeled with letters (A, B, ... Z, AA, AB...) while rows use plain numbers. This tool converts column letters to their position number and back — handy for formulas like INDEX/MATCH or scripts that address cells numerically.

⇄
Column number 1

Excel's grid runs from column A (1) to column XFD (16,384). Values outside that range, or inputs that aren't valid letters/numbers, are flagged as invalid rather than silently guessed at.
